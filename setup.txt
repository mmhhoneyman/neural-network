How to set up after leaving and reentering VS Code:
1. In the terminal: .venv\Scripts\activate
2. Sometimes the default run button doesnt work. Hit the drop down right next to it and select "run python file"


How to setup new json files for neural networks:
1. make the json file and LEAVE IT EMPTY
2. upon initializing a new NeuralNetwork object, be sure to include the new file name in its params
3. because its empty, the program will ask for permission to change it, then automatically fill it in with random seed data
